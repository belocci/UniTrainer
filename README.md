# Uni Trainer

Train AI models locally or on cloud GPUs — without code, CLI friction, or environment headaches.

Uni Trainer is a desktop-first AI training application that provides a modern GUI for training, fine-tuning, and inferencing Computer Vision, Tabular Machine Learning, and Small Language Models.

No notebooks.  
No command-line workflows.  
No fragmented tooling.

## 🧠 What Is Uni Trainer?

Uni Trainer turns AI model training into a normal product experience.

It provides a unified desktop interface for:
- Model training
- Fine tuning
- Inferencing
- Dataset handling
- Live logs and progress
- Local and cloud GPU execution

All without touching the command line.

---

## 🧩 Supported Model Types

### Computer Vision
- Image classification
- Object detection (YOLO-based)
- Automatic dataset structure handling
- Fine tuning
- Inferencing

### Tabular Machine Learning
- CSV-based classification
- CSV-based regression
- Automatic feature and target handling
- Training and inferencing

### Small Language Models
- CSV-based text datasets
- Text classification
- Fine tuning
- Inferencing
- Local-first execution

## ⚙️ Execution Modes

- Local CPU execution
- Local GPU execution (automatic detection)
- Optional cloud GPU execution via CanopyWave (In works)

Local-first by default. Cloud is optional.

## 🛠 Quick Start (Windows)

1. Download the Windows build from GitHub Releases
2. Run `UniTrainer.exe`
3. Select a dataset
4. Choose a model
5. Train, fine tune, or run inference

The repository also contains full source code for development.
