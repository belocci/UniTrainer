## 🧠 What Is Uni Trainer?

Uni Trainer is a **local-first AI training workstation**.

It unifies the full machine learning lifecycle into a single desktop application:

- Dataset ingestion and validation  
- Model selection and configuration  
- Training and fine-tuning  
- Inference and evaluation  
- Live logs, metrics, and progress  
- Local and optional cloud GPU execution  

All without writing code or managing infrastructure.

Uni Trainer is built for **individual builders, small teams, and researchers** who want control without complexity.

---

## 🧩 Supported Workflows

### 🖼 Computer Vision
- Image classification  
- Object detection (YOLO-based)  
- Automatic dataset structure detection  
- Training, fine-tuning, and inference  
- Local GPU acceleration  

### 📊 Tabular Machine Learning
- CSV-based classification  
- CSV-based regression  
- Automatic feature and target handling  
- Classical ML and deep learning models  
- Training and inference from a unified UI  

### 🧠 Small Language Models (SLMs)
- CSV and text-based datasets  
- Text classification  
- Fine-tuning workflows  
- Local-first inference  
- Lightweight model support  

### 🤖 Large Language Models (LLMs)
- Dataset import and inspection  
- LoRA / QLoRA fine-tuning  
- Chat-style inference  
- Streaming outputs and cancellation  
- Model diffing and evaluation workflows

## 🛠 Quick Start (Windows)

1. Download the Windows build from GitHub Releases  
2. Run `UniTrainer.exe`  
3. Select a dataset  
4. Choose a model  
5. Train, fine-tune, or run inference  

No setup. No configuration files. No CLI.
